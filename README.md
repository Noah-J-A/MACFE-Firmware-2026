How to run Python files: 
1. Download the Python file from GitHub
2. In the file explorer, right-click the .py file and select "Open With"
3. Open with VS Code, PyCharm, or any other IDE with Python support
4. ALTERNATIVELY (skip steps 2 and 3): Open Command Prompt/PowerShell, navigate to the folder where the Python file is stored (cd /path_to_your_folder/), and run the file by typing "python filename.py" (where filename is the name of the Python file)
